\\# GitHub Explorer

Fetch any GitHub user's public repos (name, language, stars) and save a JSON summary.



\\## Setup

python -m venv .venv

.\\.venv\\Scripts\\python.exe -m pip install -r requirements.txt



\\## Usage

python explorer.py <username>
